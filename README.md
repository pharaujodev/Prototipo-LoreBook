# LoreBook — Protótipo Mobile

Checkpoint inicial em React Native + Expo. Este projeto é totalmente separado do Ateliê Desktop e usa apenas dados fictícios/localmente mantidos durante a sessão.

## O que o protótipo demonstra

- seleção entre duas obras independentes;
- visão geral específica de cada obra;
- capítulos específicos por obra;
- editor simples;
- criação de um novo capítulo e abertura imediata no editor;
- fichas de personagens específicas por obra;
- Bíblia da obra específica por projeto;
- notas/rascunhos por obra;
- navegação inferior respeitando a área segura do Android/iOS;
- botão físico de voltar no Android seguindo a hierarquia do protótipo.

## Executar

```bash
npm install
npm start
```

Depois use Expo Go, um emulador ou a opção web oferecida pelo Expo.

## Observações

- Não existe backend ou banco real.
- Alterações e capítulos criados permanecem apenas enquanto o aplicativo está aberto.
- "Nova obra" ainda é apenas uma indicação visual deste checkpoint.
